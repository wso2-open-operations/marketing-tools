# ADR-013: PO dashboard ships in phase 1

- **Status:** Accepted
- **Date:** 2026-10-16
- **Source:** audit B6

## Context

MVP and M0b said phase 2; Roles and M5 `GET /po/dashboard` said phase 1.

## Decision

Keep the PO dashboard in phase 1. SLT reports and analytics stay phase 2.

## Consequences

- Tiles, data sources and the `GET /po/dashboard` shape still need defining (plan M0c B6).
- MVP #4, M0b and domains S4 must match.
